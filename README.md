# Speech-to-Text Accessibility App
A speech-to-text accessibility application built using React Native and Expo.

## About the Project
This project aims to help users convert spoken words into written text through a simple, accessible interface.

## Features
- Speech recognition
- Display recognized speech as text
- Microphone permission handling
- Simple user interface

## Technologies Used
- React Native
- Expo
- TypeScript
- JavaScript

## Getting Started
1. Clone the repository.
2. Open the project folder in VS Code.
3. Navigate to the mobile directory:
   ```bash
   cd mobile
   ```
4. Install dependencies:
   ```bash
   npm install
   ```
5. Start the development server:
   ```bash
   npx expo start
   ```
